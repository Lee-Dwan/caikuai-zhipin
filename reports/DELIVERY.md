## 五、本地预览（三步）

```bash
cd caikuai-zhipin
pip install -r requirements.txt
python3 scripts/serve.py            # 打开 http://127.0.0.1:8080/
```

不装 Python 也能预览：直接双击 `index.html`，会读取 `assets/js/data-fallback.js` 兜底数据。

## 六、上线（详见 DEPLOY-CLOUDFLARE.md）

1. 代码推到 GitHub 公共仓库；
2. 仓库 Settings → Actions → Workflow permissions 选 **Read and write**；
3. Cloudflare Pages → Connect to Git → 选仓库 → Build command 留空、输出目录 `/` → Save and Deploy；
4. 得到 `https://<项目名>.pages.dev`，此后每天 08:00 Actions 自动采集 → 提交 → Pages 自动重新部署，链接不变。

## 七、已知限制与后续建议

- 安永 Taleo 详情页响应慢（首次全量约 4~8 分钟），已加本地缓存，次日运行仅十几秒；如 Actions 偶发超时，可把 `ey.py` 的 `DETAIL_LIMIT` 调低。
- 信永中和对高频详情请求敏感，已做“缓存 + 约 1 秒间隔 + 每轮最多 70 条新详情”，三轮均未触发封禁；如遇连接重置会自动保留历史数据并标记异常。
- 容诚无独立岗位详情页（弹层展示），投递链接统一指向官方门户首页，详情内已注明“官方来源”。
- 今日新增在首次建立基线当天显示 0（没有可比的上一次快照），次日起按自然日统计。
- 二维码位为占位块，替换 `index.html` 中 `qr-ph` 为 `<img>` 即可。
